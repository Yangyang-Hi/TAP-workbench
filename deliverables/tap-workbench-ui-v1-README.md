## 构建方式与宿主兼容

本地不能取得私有@aime-plugin/browser-sdk，未伪造/替换SDK，也未重编整套原生宿主。安装包保留用户上传的真实SDK及其他编译模块；主模块只做有清单的显示文案/图表颜色替换，没有改业务表达式；替换后使用新内容哈希文件名防止旧缓存。新增CSS和阅读辅助脚本使用esbuild构建，通过index.html加载。

新主题仅在业务工作台/独立任务页出现时作用，不替换AimeProvider、AuthGuard、page-control、宿主监控或鉴权实现。导出HTML的后端模板未改，仍为原报告版本。
